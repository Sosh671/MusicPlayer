# MusicPlayer

A simple Android music player built using **Media3**, **Jetpack Compose**, **Kotlin**, and **Koin**. This app allows users to play music tracks, browse songs, and manage playback with a modern, native Android UI.

### Features:

- **Media3 Integration** for audio playback.
- **Jetpack Compose UI** for a modern, declarative UI approach.
- **Koin** for dependency injection.
- Supports background music playback.
- Play/pause, skip, and track progress features.
- Custom music controls and playback UI.

### Tech Stack

Here’s what I used to build this app:

- **Kotlin**: The primary language for Android development. It’s concise, expressive, and fully supported by Android.
- **Jetpack Compose**: A UI toolkit for building native Android UIs in a more declarative way, reducing the need for XML.
- **Media3**: A library from Google that provides support for audio playback and streaming, making it easy to handle media files.
- **Koin**: A lightweight dependency injection library for **Kotlin**, simplifying how dependencies are managed and provided throughout the app.

# MusicPlayer

Media3、Jetpack Compose、Kotlin、およびKoinを使用して作成したシンプルなAndroidミュージックプレーヤーです。このアプリでは、ユーザーが音楽トラックを再生したり、曲をブラウズしたり、モダンでネイティブなAndroid UIを使用して再生を管理できます。

### 特徴:

- **Media3統合**でオーディオ再生をサポート。
- **Jetpack Compose UI**で、モダンで宣言的なUIアプローチ。
- **Koin**による依存性注入。
- バックグラウンドでの音楽再生をサポート。
- 再生/一時停止、スキップ、進行状況の追跡機能。
- カスタム音楽コントロールと再生UI。

### テクノロジースタック

このアプリを構築するために使用した技術は以下の通りです：

- **Kotlin**: Android開発のための主要なプログラミング言語。簡潔で表現力があり、Androidに完全対応しています。
- **Jetpack Compose**: 宣言的な方法でネイティブAndroid UIを構築するためのUIツールキット。XMLの必要性を減らします。
- **Media3**: オーディオ再生とストリーミングをサポートするGoogleのライブラリ。メディアファイルの取り扱いが簡単です。
- **Koin**: Kotlinの軽量な依存性注入ライブラリ。アプリ内での依存関係の管理と提供を簡素化します。
